THE CONTEXT WINDOW — Platform Setup Checklist
========================================

Everything below is optional. The pipeline runs fine without any of
this — YouTube uploads will keep working daily as-is. Set these up
whenever you have time.


1. TIKTOK (clips auto-post)
----------------------------
Status: Code is ready (refresh-token flow — access tokens only live 24h,
so the pipeline mints a fresh one each run).

[ ] Go to https://developers.tiktok.com, sign up, create an app
[ ] Add BOTH products: "Login Kit" and "Content Posting API" (Direct Post)
[ ] Register a Redirect URI under Login Kit (any URL you control — your
    website works; nothing needs to be deployed there)
[ ] Request scopes: user.info.basic, video.upload, video.publish
[ ] Submit for review (may take a few days; they often ask for a short
    demo recording of the integration)
[ ] Copy Client key + Client secret. Add to .env:
      TIKTOK_CLIENT_KEY=...
      TIKTOK_CLIENT_SECRET=...
      TIKTOK_REDIRECT_URI=...   (exactly as registered)
[ ] Run: python get_tiktok_token.py
    Sign in with the account that should post, approve, paste the URL
    you land on. It prints TIKTOK_REFRESH_TOKEN.
[ ] Add TIKTOK_CLIENT_KEY / TIKTOK_CLIENT_SECRET / TIKTOK_REFRESH_TOKEN
    as repo secrets.

NOTE: until TikTok audits the app, API posts can only be private
(SELF_ONLY) — the pipeline defaults to that. After the audit passes,
add a repo *variable* TIKTOK_PRIVACY_LEVEL=PUBLIC_TO_EVERYONE
(Settings → Secrets and variables → Actions → Variables tab).


2. CLOUDFLARE R2 — podcast audio hosting (~5 min, basically free)
-----------------------------------------------------------------
Status: Code is ready. This is needed before Spotify/Apple work.
Cost: ~$0.01/month per episode. Free egress. First 10GB free.

[ ] Sign up at https://cloudflare.com (free account works)
[ ] Dashboard → R2 Object Storage → Create Bucket
    - Name it something like "ai-daily-podcast"
[ ] Bucket Settings → Public Access → Allow public access
    - Note the public URL (looks like https://pub-abc123.r2.dev)
[ ] Dashboard → R2 → Manage R2 API Tokens → Create Token
    - Permissions: Object Read & Write
    - Scope: just your bucket
    - Save the Access Key ID and Secret Access Key
[ ] Add to .env:
      R2_ENDPOINT_URL=https://<your-account-id>.r2.cloudflarestorage.com
      R2_ACCESS_KEY_ID=your_key
      R2_SECRET_ACCESS_KEY=your_secret
      R2_BUCKET_NAME=ai-daily-podcast
      R2_PUBLIC_URL=https://pub-abc123.r2.dev

Your account ID is in the Cloudflare dashboard URL or R2 overview page.


3. GUEST AI HOSTS (Gemini / Grok)
----------------------------------
Status: Code is ready. Guests auto-join on Fridays once keys are added.
No key = they won't appear (no one speaks unless they write their own lines).

[ ] For Gemini: https://aistudio.google.com/apikey
    - Create an API key (free tier: 15 requests/min)
    - Add to .env: GOOGLE_AI_API_KEY=your_key

[ ] For Grok: https://console.x.ai
    - Create an API key (requires xAI account)
    - Add to .env: XAI_API_KEY=your_key

Once added, the next Friday episode will automatically include a guest.
Guests rotate weekly (week 1: Gemini, week 2: Grok, etc).
Force a guest anytime: python main.py --guest Gemini
Force all speakers:    python main.py --roundtable

==========================================

  - Anthropic API (script + rewrites):   ~$10-20/month

If you add everything:
  - Cloudflare R2 storage:               ~$0.30/month (basically free)
  - Google AI (Gemini guest, Fridays):    free tier
  - xAI/Grok (Grok guest, Fridays):      ~$2-5/month
  - TikTok:                              free

Total with everything: ~$30-55/month for a fully automated daily
podcast across YouTube and TikTok.
